# Roadmap

## v1.x

- Expand framework adapters based on real-world usage.
- Add more domain profiles without duplicating the core engine.
- Add evaluation fixtures from real website tasks.
- Improve machine-readable audit/report schemas.

## Non-goals

ShriForgeAISkill is not intended to become a universal application backend framework, a frozen copy of official documentation, or a bundle of hundreds of overlapping prompts.
