# Static HTML/CSS/JS Adapter

Use for framework-free sites.

- Use semantic HTML and progressively enhanced JavaScript.
- Keep CSS organized around clear tokens/components/layouts appropriate to project size.
- Avoid adding a framework merely for simple navigation, forms, or presentation effects.
- Optimize assets and include correct metadata/canonical/sitemap/robots where deployment permits.
- For forms requiring a server, use the project's chosen service/backend rather than exposing secrets in client JavaScript.
