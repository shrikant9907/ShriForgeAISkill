# Responsive Design

Treat responsiveness as content/layout adaptation, not only breakpoint scaling.

Review:
- 320px-class small screens through large desktops;
- navigation and menus;
- text wrapping and reading width;
- media aspect ratios;
- tables/data overflow;
- forms and touch targets;
- sticky/fixed UI collisions;
- landscape and zoom/reflow;
- device-safe spacing where relevant.

Use fluid layout primitives before adding many breakpoints.
