# Information Architecture

Organize content around user intent and findability.

Rules:
- primary navigation should expose high-value destinations;
- page titles and labels should use audience language;
- combine thin/overlapping pages;
- use breadcrumbs for deep hierarchical structures when useful;
- ensure important pages are internally linked and not orphaned;
- preserve useful URLs during restructures or provide redirects;
- navigation depth should reflect content complexity, not arbitrary limits.
