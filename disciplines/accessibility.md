# Accessibility

Aim for robust WCAG-aligned accessibility appropriate to the project and current standards.

Review:
- semantic landmarks/headings;
- keyboard operability;
- visible focus;
- accessible names/labels;
- form errors and instructions;
- contrast and non-color cues;
- meaningful alternative text;
- reduced-motion preferences;
- zoom/reflow and text scaling;
- dialogs/menus/tabs/accordions behavior;
- screen-reader order and announcements where needed.

Use native elements whenever they provide the required semantics and behavior. Automated tools help but do not replace keyboard/screen-reader-oriented review for important interactions.
