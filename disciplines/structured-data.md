# Structured Data

Use schema only when it accurately represents visible, supported content.

Possible types depend on the project, such as:
- Organization / LocalBusiness / School / EducationalOrganization;
- WebSite / WebPage;
- BreadcrumbList;
- Person;
- Article / NewsArticle;
- Event;
- FAQPage only when the page genuinely qualifies under current guidance.

Rules:
- prefer one canonical data model over hand-written conflicting JSON-LD fragments;
- keep names/URLs/contact details consistent with visible content;
- never mark up fake ratings, reviews, awards, prices, events, or credentials;
- validate generated JSON and, when tools permit, current eligibility requirements.
