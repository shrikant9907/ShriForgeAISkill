# Deployment & Documentation

For production handoff, make the project operable by another maintainer.

Document as applicable:
- install and development commands;
- package manager;
- build/start commands;
- environment variable names and purpose (never secret values);
- deployment provider/configuration;
- domain/canonical configuration;
- content/CMS update path;
- test/quality commands;
- known limitations/placeholders;
- migration/rollback considerations for risky releases.

Update existing README/docs rather than creating redundant documentation files.
