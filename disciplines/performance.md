# Performance

Optimize user-perceived speed without harming maintainability or accessibility.

Review:
- properly sized responsive images;
- font loading/subsetting strategy;
- JavaScript shipped to the client;
- unnecessary client components/hydration;
- render-blocking resources;
- third-party scripts;
- caching and static generation opportunities;
- layout shifts and stable dimensions;
- lazy loading for below-the-fold media where appropriate.

Use current Core Web Vitals guidance when measuring. Do not invent performance scores that were not measured.
