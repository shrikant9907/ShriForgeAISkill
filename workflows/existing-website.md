# Existing Website Workflow

Use for broad work in an existing repository that spans multiple pages or concerns.

## Sequence

1. Run repository discovery.
2. Mark healthy conventions/infrastructure to preserve.
3. Classify the requested outcome and map change surface.
4. Identify truth/content sources and material unknowns.
5. Select only needed disciplines and the existing framework adapter.
6. Implement in coherent increments.
7. Run changed-surface checks plus shared regression checks.
8. Update documentation only when behavior/setup changed.

Do not re-scaffold or replace working infrastructure without a concrete requirement or demonstrated problem.


## Contract

- Inspect before editing when a repository exists.
- Establish project truth when factual content is involved.
- Load only required disciplines and one adapter if needed.
- Map change surface before shared or risky changes.
- Validate proportionally and re-run affected checks after fixes.
- Finish with an explicit completion state for substantial work.
