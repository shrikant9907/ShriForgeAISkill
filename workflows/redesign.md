# Redesign Workflow

Use when the primary goal is visual quality, hierarchy, interaction, usability, or brand expression.

## Sequence

1. Preserve factual content and business behavior unless explicitly changing them.
2. Identify current usability/design problems and target audience perception.
3. Establish a deliberate visual direction: typography, spacing, color, imagery, composition, motion.
4. Reuse or evolve the existing design system where practical.
5. Implement responsively and semantically.
6. Validate keyboard/focus, contrast, reflow, motion preferences, image/layout performance.

Avoid generic AI/SaaS aesthetics, decorative complexity without purpose, and animation that harms usability.


## Contract

- Inspect before editing when a repository exists.
- Establish project truth when factual content is involved.
- Load only required disciplines and one adapter if needed.
- Map change surface before shared or risky changes.
- Validate proportionally and re-run affected checks after fixes.
- Finish with an explicit completion state for substantial work.
