# Search Optimization Workflow

Use for SEO, AEO/GEO, local search, metadata, crawlability, entities, internal linking, or structured-data work.

## Sequence

1. Confirm business facts and target audiences/intents.
2. Inspect crawl/index controls, metadata, canonicals, sitemap/robots, rendering, internal links, and content structure.
3. Improve page usefulness before keyword repetition.
4. Clarify entities, locations, services/topics, and answer-oriented sections where genuine.
5. Add structured data only when applicable and supported by visible factual content.
6. Validate consistency and avoid fake FAQs/reviews/ratings/schema.

Search optimization must never weaken content truth or user experience.


## Contract

- Inspect before editing when a repository exists.
- Establish project truth when factual content is involved.
- Load only required disciplines and one adapter if needed.
- Map change surface before shared or risky changes.
- Validate proportionally and re-run affected checks after fixes.
- Finish with an explicit completion state for substantial work.
