# Content Update Workflow

Use when the task primarily changes copy, people, contact information, notices, dates, facts, pricing/fees, policies, or editorial content.

## Sequence

1. Verify the source and exact supported claim.
2. Locate all duplicate representations of the information.
3. Update canonical content/data source first when one exists.
4. Check metadata, structured data, local-search consistency, links, and UI labels where affected.
5. Confirm no stale or conflicting version remains.
6. Ensure placeholders are not presented as live facts.


## Contract

- Inspect before editing when a repository exists.
- Establish project truth when factual content is involved.
- Load only required disciplines and one adapter if needed.
- Map change surface before shared or risky changes.
- Validate proportionally and re-run affected checks after fixes.
- Finish with an explicit completion state for substantial work.
