# Security Policy

ShriForgeAISkill is primarily an instruction repository plus local validation scripts. Security issues may still exist in scripts, examples, or guidance.

Please report suspected vulnerabilities privately to the repository maintainers through the hosting platform's private vulnerability-reporting mechanism when available. Do not include real secrets, credentials, or private project data in public issues.

Security guidance in ShriForgeAISkill is general and must be adapted to the actual application's threat model.
