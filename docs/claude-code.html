CLAUDE CODE GUIDE

Build complete production websites with Claude Code.

ShriForgeAISkill gives Claude Code a reusable production web engineering workflow instead of a one-off website prompt. It coordinates repository inspection, Project Truth, intent-first architecture, design, implementation and quality validation.

Install ShriForgeAISkill in a project

Clone the repository into a Claude Code skills directory supported by your setup. A project-local example is:

git clone https://github.com/shrikant9907/ShriForgeAISkill.git \
  .claude/skills/shriforge-ai-skill

The directory containing SKILL.md is the skill root.

What should I ask Claude Code?

Ask for the outcome you want and provide real business facts when they matter. ShriForgeAISkill is responsible for routing the task through the relevant workflow and quality disciplines.

Use ShriForgeAISkill to build a production-ready website for my agency.

Inspect the repository first. Create a distinctive visual direction.
Make the experience responsive and accessible. Implement truthful SEO,
AEO/GEO and structured data. Review performance and security.
Test the result and return an explicit release status.

Which Claude Code website tasks fit the skill?

  • Build a complete new website.
  • Add a page or feature to an existing website.
  • Redesign a homepage without replacing healthy business logic.
  • Audit SEO, AEO/GEO, accessibility, performance or security.
  • Fix a website bug with proportional regression checks.
  • Migrate or prepare a website for production release.

How is this different from a frontend-design-only skill?

A design-focused skill can improve visual output. ShriForgeAISkill covers the broader website lifecycle: verified facts, visitor intent, architecture, implementation, discoverability, accessibility, performance, security, testing and release confidence. Design is one discipline inside the system, not the entire system.

How does it avoid context bloat?

The master SKILL.md acts as an orchestrator. It should load only the workflow, disciplines, framework adapter and domain profile needed for the current task rather than loading the entire repository every time.
