01 / FULL WEBSITE LIFECYCLE

More than a website generator.
A production methodology.

ShriForgeAISkill coordinates the work that normally gets split across separate design, frontend, SEO, accessibility, performance, security and QA prompts.

01

Project Truth

Stop AI agents from turning assumptions into business claims.

Facts, requirements, rules, decisions, assumptions and unknowns are tracked separately. If a school affiliation, award, statistic, testimonial or credential is not verified, the skill does not present it as fact.

05 / QUICK ANSWERS

Frequently asked
questions.

What is ShriForgeAISkill?

ShriForgeAISkill is an open-source AI Agent Skill that gives coding agents a structured method to plan, design, build, audit, validate and ship production-ready websites.

Can I use ShriForgeAISkill with Claude Code?

Yes. Clone the repository into a Claude Code skills directory, then ask Claude Code to build, improve or audit a website. The directory containing SKILL.md is the skill root.

Can I use it with Codex or another AI coding agent?

Yes, when the agent can read repository files. Make ShriForgeAISkill available in the workspace and explicitly instruct the agent to read SKILL.md and follow its routing, Project Truth and quality-gate instructions. Native skill discovery varies by tool.

How does it prevent AI from inventing business facts?

The Project Truth model keeps verified facts separate from requirements, rules, decisions, assumptions and unknowns. Unverified claims should be omitted, clearly marked or requested when essential.

How does it decide a website is ready to ship?

It runs the quality gates applicable to the task and returns one of four explicit states: PASS, PASS_WITH_NOTES, BLOCKED or FAIL.
