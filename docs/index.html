01 / THE SYSTEM

Not a giant prompt.
A production methodology.

One orchestrator routes only the modules that matter for the current task, keeping context focused while protecting engineering quality.

01

Project Truth

Facts stay facts. Assumptions stay visible.

Separate FACT, REQUIREMENT, RULE, DECISION, ASSUMPTION, and UNKNOWN so agents do not silently invent business claims.

FACT REQUIREMENT DECISION ASSUMPTION
02

Intent architecture

Start with what people need to accomplish.

Audience → intent → information → trust → page → content → action.

Audience→Intent→Action
03

Change surface

Understand impact before touching code.

Map routes, components, content, tests, metadata, accessibility, and deployment implications before significant edits.

04

Quality loop

Build. Validate. Fix. Re-validate.

Generated code is not the finish line. Applicable quality gates decide whether work is actually complete.

05

Release confidence

Completion is explicit.
