## On-page rules

- One descriptive title and meta description per page.
- One canonical URL per page.
- Direct answer in the first paragraph of important sections.
- One primary topic per page; do not repeat all target phrases everywhere.
- Internal links between related pages.
- Visible FAQ answers must match FAQPage structured data.
- Structured data must describe visible, truthful content only.
- No fake ratings, reviews, awards, installation counts or ranking claims.
- Do not use meta-keywords; they are not part of this strategy.

## Distribution work outside the repository

On-page optimization alone will not create authority. Maintain a separate outreach/distribution process for relevant skill directories, curated lists, developer communities, backlinks and real usage examples. Measure impressions/clicks in Google Search Console when available, then update content from observed queries rather than stuffing every possible keyword onto one page.
