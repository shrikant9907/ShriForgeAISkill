# Research & Provenance

ShriForgeAISkill is written as an original methodology. It does not bundle or copy third-party skill repositories.

The architecture was informed by general ideas from public agent-skill ecosystems and established web-engineering practices: progressive disclosure, specialized workflows, repository inspection, current framework documentation, accessibility, search discoverability, testing, security, and open-source governance.

Before incorporating third-party code or substantial text in future contributions, record:
- source repository and exact revision;
- license;
- copied/adapted material;
- attribution/NOTICE requirements;
- why reimplementation is insufficient.

General ideas and interoperability observations should be re-expressed in ShriForgeAISkill's own structure and language.
