FAQ / DIRECT ANSWERS

Questions about ShriForgeAISkill.

These answers explain how the skill works, where it fits, and how to use it with modern AI coding agents. Each answer is intentionally direct so both people and answer engines can understand the project without guessing.

What is ShriForgeAISkill?

ShriForgeAISkill is an open-source AI Agent Skill for planning, designing, building, auditing, optimizing and shipping production-ready websites. It coordinates product thinking, web design, frontend engineering, search discoverability and quality validation through one selective workflow system.

What AI coding tools can use ShriForgeAISkill?

Claude Code can use it from a skills directory. Codex and other repository-aware coding agents can use it when the skill files are available and the agent is explicitly told to read SKILL.md. Native discovery differs by tool, so the portable fallback is direct repository-file instructions.

How do I install ShriForgeAISkill in Claude Code?

Clone the repository into a Claude Code skills directory supported by your environment, such as a project-local .claude/skills/shriforge-ai-skill/ directory. The directory containing SKILL.md is the skill root.

How do I use ShriForgeAISkill with Codex?

Make the repository readable to Codex and tell it to read ShriForgeAISkill/SKILL.md before the project task. Ask it to follow the task classifier, Project Truth, selective routing, change-surface analysis and applicable quality gates.

What makes ShriForgeAISkill different from a simple AI website builder?

It is a production methodology rather than a page generator. The skill starts with repository state, facts and visitor intent; then routes design, engineering, SEO/AEO/GEO, accessibility, performance, security, testing and release validation as needed.

What is Project Truth?

Project Truth is the evidence model that separates FACT, REQUIREMENT, RULE, DECISION, ASSUMPTION and UNKNOWN. It helps prevent AI-generated websites from publishing unverified affiliations, awards, statistics, testimonials, credentials or other business claims.

What does intent-first architecture mean?

Intent-first architecture derives pages and sections from audience goals and information needs. The sequence is audience → intent → information → trust → page/section → content → action, rather than generating a generic page list first.

Does ShriForgeAISkill include SEO, AEO and GEO?

Yes. Its search disciplines cover technical SEO, answer-oriented content, AI-search/GEO considerations, local search, metadata, crawlability, internal linking and truthful structured data where applicable.

Does ShriForgeAISkill guarantee first-page Google rankings?

No. No skill or on-page optimization can honestly guarantee rankings or a specific time to rank. ShriForgeAISkill can improve technical discoverability, content clarity and machine-readable signals, but rankings also depend on competition, authority, backlinks, user demand, indexing and other external factors.

How does ShriForgeAISkill decide a website is production-ready?

It applies the release gates relevant to the project, including requirements, repository integrity, build/static quality, functionality, responsive UX, accessibility, search, content truth, performance, security, privacy, maintainability and deployment readiness. It returns PASS, PASS_WITH_NOTES, BLOCKED or FAIL.

Can a beginner use ShriForgeAISkill?

Yes. A beginner can describe the desired website outcome and provide verified business information. The skill is designed to make the coding agent handle the engineering methodology, while still exposing assumptions, blockers and validation results instead of hiding them.

Which frameworks are covered?

The current repository includes adapters for Next.js App Router, React/Vite, Astro and static HTML/CSS/JavaScript. The core methodology is framework-neutral so additional adapters can be added without rewriting the whole skill.
