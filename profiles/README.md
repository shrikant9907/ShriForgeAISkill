# Project Profiles

Profiles specialize ShriForgeAISkill for specific industries and use cases. They provide intents, content models, risk reminders, and claim policies—not framework rules and not invented facts.

## Available Profiles

- `profiles/school-india.md` — Schools, colleges, and educational institutions in India.
- `profiles/local-business.md` — Local service businesses, contractors, and retail shops.
- `profiles/saas-marketing.md` — B2B/B2C SaaS marketing and product landing pages.
- `profiles/ecommerce-store.md` — Online storefronts, product catalogs, and D2C brands.
- `profiles/healthcare-clinic.md` — Hospitals, clinics, doctors, and medical practices.
- `profiles/developer-docs.md` — Developer hubs, API references, and documentation sites.
