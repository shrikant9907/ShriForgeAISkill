# Profile: Developer Documentation & Knowledge Base

Use for API references, developer hubs, technical product documentation, and SDK guides.

## Typical Audiences

- software engineers evaluating an API or library;
- developers implementing specific endpoints or integration steps;
- maintainers debugging errors or deprecation warnings;
- AI coding agents crawling documentation for context.

## Common Intents

- locate installation commands and "Quickstart" in under 30 seconds;
- copy syntax-highlighted code snippets with single-click clipboard action;
- search for specific functions, error codes, and parameters;
- check version compatibility and changelogs;
- consume LLM-friendly summaries via `llms.txt`.

## Useful Surfaces

Overview/Quickstart, Guides/Tutorials, API Reference, SDKs/Libraries, Error Codes, Changelog, FAQ/Community.

## UX & Content Guidance

- Code blocks must declare language identifiers and support clear copy UX;
- Provide runnable, realistic examples rather than abstract pseudocode;
- Maintain dark/light mode contrast for syntax highlighting;
- Provide clean table of contents with anchor links for deep referencing;
- Include an `llms.txt` file at root summarizing the API for AI agents.
