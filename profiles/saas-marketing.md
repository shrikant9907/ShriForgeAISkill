# Profile: SaaS Marketing Site

Prioritize:
- target user/problem;
- product value and differentiation supported by evidence;
- feature/use-case architecture;
- pricing only when supplied/current;
- proof such as customer logos/testimonials only when authorized;
- docs/demo/signup/contact journeys;
- integration/security/compliance claims only when verified.

Avoid generic dashboard mockups, fake metrics, invented customers, unsupported "enterprise-grade" claims, and excessive animation that slows the primary story.
