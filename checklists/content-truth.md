# Content Truth Checklist

- [ ] Each material factual claim has a source
- [ ] No assumption is presented as fact
- [ ] Names, address, phone, email are consistent
- [ ] Dates/pricing/fees are current enough for publication
- [ ] Awards/ratings/reviews/testimonials are verified
- [ ] Credentials/affiliations/accreditations are verified
- [ ] Structured data matches visible content
- [ ] Development placeholders are clearly non-live or removed
