# Continuous Quality Loop

For meaningful work:

`UNDERSTAND → PLAN → IMPLEMENT → VALIDATE → FIND → PRIORITIZE → FIX → RE-VALIDATE`

## Prioritization

1. `BLOCKER` — cannot safely call the requested outcome complete.
2. `HIGH` — material functional, security, accessibility, search, or data risk.
3. `MEDIUM` — meaningful quality/maintainability issue.
4. `LOW` — polish/non-critical improvement.

Fix blockers/high issues when possible. If blocked by missing credentials, data, environment, or external service, report the blocker precisely rather than pretending the gate passed.
